## ✨ Fitur Utama

- 📡 **Koneksi Wireless Instant:** Terhubung secara otomatis ke unit RG Gyro terdekat.
- 🎛️ **Tuning Parameter Real-Time:** Penyesuaian sensitivitas **AGS** *(Anti-Glitch System)*, **PCA** *(Priority Control Assist)*, dan **DLY** *(Response Delay)*.
- 📐 **EPA Calibration Wizard:** Panduan langkah demi langkah untuk melakukan kalibrasi batas fisik servo *(End Point Adjustment)*.
- 🔄 **Reverse Mode Toggle:** Mengubah arah koreksi kemudi otomatis *(Counter-Steer Direction)*.
- 🏷️ **Kustomisasi Nama Perangkat:** Mengubah nama perangkat RG Gyro secara langsung dari aplikasi (Format: `RG-[NamaCustom]`).
- 🔄 **Auto-Update Notifier:** Aplikasi mendeteksi rilis pembaruan baru dari server secara otomatis.
- 🌗 **Tema Visual Dark / Light:** Mode tampilan futuristik yang dapat disesuaikan.
- 🌐 **Dukungan Multabahasa:** Tersedia dalam Bahasa Indonesia 🇮🇩 dan English 🇬🇧.
